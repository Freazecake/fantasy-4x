# fantasy-4x

Пошаговая 4X-стратегия в фэнтезийном сеттинге на C++17 и Qt. Вы развиваете поселение выбранной расы, соперничаете с ботами и побеждаете, оставшись единственным правителем на карте: военным путём или политическим поглощением.

> Проект учебный, находится в разработке.

## Возможности

- 5 играбельных рас с разными сильными сторонами: люди, дворфы, гномы, эльфы, орки.
- Экономика на населении: люди распределяются между четырьмя сферами (наука, промышленность, торговля, дипломатия) и могут свободно переходить между ними.
- Постройки с очередью, ветвящееся дерево технологий, торговый обмен очков.
- Именные герои, дающие бонус к своей сфере.
- Военная сфера: юниты создаются из населения и промышленности. Без казармы юниты слабее, а продвинутые недоступны.
- Два пути к победе: военный и политический (за дипломатические очки).
- Противники под управлением ИИ (Utility AI с memory).

## Расы

| Раса | Сильная сторона | Слабая сторона |
|---|---|---|
| Люди | универсалы, торговля и дипломатия | нет явных провалов |
| Дворфы | промышленность и армия | дипломатия, рост населения |
| Гномы | наука | армия |
| Эльфы | наука | промышленность, рост населения |
| Орки | армия и быстрый рост | наука, торговля, дипломатия |

## Требования

- Компилятор с поддержкой C++17
- CMake
- Qt 6 (Widgets)

## Сборка и запуск

```bash
mkdir build
cd build
cmake ..
cmake --build .
./fantasy-4x
```

Данные игры (расы, постройки, технологии, юниты) лежат в папке `data/` в формате JSON и могут быть изменены без пересборки.

## Как играть

1. Выберите расу и начните партию против 2–3 ботов.
2. Кликайте по карте, чтобы выбрать поселение.
3. В панели поселения распределите население по сферам, поставьте постройки в очередь и наймите юнитов.
4. В панели технологий выберите, что исследовать.
5. Нажмите «Конец хода». Боты сделают свои ходы, и начнётся следующий ход.
6. Партия заканчивается, когда на карте остаётся один правитель.

## Структура проекта

```
src/
  core/   игровая логика на чистом C++ (без Qt)
  ai/     логика ботов
  gui/    интерфейс на Qt: карта, панели, управление ходом
  main.cpp
data/     races.json, buildings.json, technologies.json,
          political_actions.json, heroes.json, units.json
```

Логика игры отделена от интерфейса: `core/` и `ai/` ничего не знают о Qt, поэтому их можно тестировать из консоли.
